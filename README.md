# Matjar Palestine

Create a modern, elegant Palestinian e-commerce website called "متجر فلسطين".

The website should be in Arabic RTL (Right-to-Left) and fully responsive for desktop, tablet, and mobile.

Design Style

Use a clean, premium, modern design inspired by Palestinian culture.

Main colors:

Dark olive green: #315B3A

Soft olive green: #6F8F64

Cream: #F7F5EF

White: #FFFFFF

Dark text: #26352B

Small red accents inspired by the Palestinian flag

Use rounded cards, soft shadows, lots of whitespace, elegant typography, and subtle hover animations.

Do NOT make the design complicated. Keep it simple, professional, and easy to navigate.

Create a thin top announcement bar with Arabic text:
